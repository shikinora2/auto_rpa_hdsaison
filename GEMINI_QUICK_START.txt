✅ ĐÃ HOÀN THÀNH:

1. Thêm UI vào Tab "Tác Vụ":
   ✓ Frame "KẾT NỐI API GEMINI"
   ✓ Entry nhập API Key (có ẩn/hiện)
   ✓ Checkbox "Hiện API Key"
   ✓ Label trạng thái kết nối
   ✓ Nút "Kết Nối Gemini"

2. Thêm các hàm xử lý:
   ✓ toggle_api_key_visibility() - Hiện/ẩn API Key
   ✓ connect_gemini() - Xử lý kết nối
   ✓ _run_gemini_connection() - Thread worker kết nối API
   ✓ _save_gemini_config() - Lưu API Key
   ✓ _load_gemini_config() - Load API Key tự động

3. Tự động lưu/load API Key:
   ✓ File: app_data/gemini_config.json
   ✓ Mã hóa base64 trước khi lưu

BƯỚC 1: Cài đặt thư viện
────────────────────────────────────────────────────────────────
pip install google-generativeai


BƯỚC 2: Lấy API Key
────────────────────────────────────────────────────────────────
1. Truy cập: https://makersuite.google.com/app/apikey
2. Đăng nhập Google
3. Click "Create API Key"
4. Copy API Key


BƯỚC 3: Cập nhật code trong app_ui.py
────────────────────────────────────────────────────────────────
Tìm hàm: _run_gemini_connection (dòng ~1270)

Thay thế phần code giả lập bằng:

    import google.generativeai as genai
    
    genai.configure(api_key=api_key)
    model = genai.GenerativeModel('gemini-pro')
    
    response = model.generate_content("Xin chào")
    
    if response and response.text:
        self.gemini_model = model  # Lưu model
        # ... code còn lại ...


BƯỚC 4: Thêm biến instance
────────────────────────────────────────────────────────────────
Trong hàm __init__ (dòng ~75), thêm:

    self.gemini_model = None


BƯỚC 5: Test kết nối
────────────────────────────────────────────────────────────────
1. Chạy ứng dụng
2. Vào tab "Tác Vụ"
3. Nhập API Key
4. Click "Kết Nối Gemini"
5. Kiểm tra log
